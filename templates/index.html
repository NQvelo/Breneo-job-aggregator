Primary Endpoints v1

The main resource-based endpoints for integrating with frontend applications.

  • GET /api/v1/jobs/
    List, Search & Filter Jobs
  • GET /api/v1/jobs/{id}/
    Get Single Job Details

Features: Pagination, Search (?search=), Filtering (?location=, ?company=), Sorting (?sort=), Field Selection (?fields=).

All Filters & API Examples

When a parameter has 2 or more values, separate them with a comma. Examples: title=Engineer,Developer, country=us,uk, role_category=frontend,backend,data. A job matches if it matches any value in that filter.

Search endpoint: GET /api/search

Example URLs (search) — multiple values comma-separated:

/api/search?title=Engineer,Developer /api/search?country=us,uk /api/search?role_category=frontend,backend&work_mode=remote,hybrid /api/search?country=us,uk&seniority=senior,mid&date_posted=week

CV view tracking — how it works

Table job_applicant_cv_views stores when employer staff open an applicant’s CV for a job. Unique per (job, applicant_user_id, viewer_user_id). Repeat opens increment view_count.

1
Applicant applies BFF POST /api/jobs/{job_id}/apply
2
Employer lists applicants Employer GET /api/jobs/{job_id}/applicants
Each row includes employer_viewed_cv, cv_viewed_by_me
3
Employer opens CV page → record view Employer POST /api/jobs/{job_id}/applicants/{applicant_user_id}/cv-view?external_user_id={staffId}
Call once on page load. Creates row or increments view_count.
4
Applicant sees “Employer viewed your CV” BFF GET /api/users/me/applications
Fields: employer_viewed_cv, employer_first_viewed_at, employer_cv_view_count
5
Applicant notification list BFF GET /api/users/me/cv-views
6
Applicant acknowledges notification BFF PATCH /api/users/me/cv-views/{cv_view_id}
Body: { "acknowledge": true } sets applicant_acknowledged_at
7
Employer admin CRUD (optional) Employer /api/jobs/{job_id}/applicant-cv-views[/{cv_view_id}]
GET list · POST create · PATCH edit · DELETE remove
MethodsPathWhoDescription
POST/api/jobs/{job_id}/applicants/{applicant_user_id}/cv-viewEmployerRecord/increment view (shortcut)
GET, POST/api/jobs/{job_id}/applicant-cv-viewsEmployerList or manually create rows
GET, PATCH, DELETE/api/jobs/{job_id}/applicant-cv-views/{cv_view_id}EmployerGet, edit, delete one row
GET/api/users/me/cv-viewsApplicantList views on my profile
GET, PATCH/api/users/me/cv-views/{cv_view_id}ApplicantGet or acknowledge one view

Row fields: id, job_id, job_title, company_name, applicant_user_id, viewer_user_id, first_viewed_at, last_viewed_at, view_count, applicant_acknowledged_at
