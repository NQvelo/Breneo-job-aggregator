Job Aggregator API

RESTful API for accessing and searching job listings

Primary Endpoints v1

The main resource-based endpoints for integrating with frontend applications.

  • GET /api/v1/jobs/
    List, Search & Filter Jobs
  • GET /api/v1/jobs/{id}/
    Get Single Job Details

Features: Pagination, Search (?search=), Filtering (?location=, ?company=), Sorting (?sort=), Field Selection (?fields=).

All Filters & API Examples

When a parameter has 2 or more values, separate them with a comma. Examples: title=Engineer,Developer, country=us,uk, role_category=frontend,backend,data. A job matches if it matches any value in that filter.

Search endpoint: GET /api/search

ParameterTypeDescription
querystringNatural language search (e.g. "software engineer", "backend OR frontend")
title_filterstringDirect title filter (Google-like syntax); overrides query
titlemultiTitle keywords, comma-separated (e.g. title=Engineer,Developer)
countrymultiCountry codes, comma-separated (e.g. country=us,uk)
location_countrymultiLocation country names, comma-separated (e.g. location_country=USA,Germany)
role_categorymultiComma-separated: frontend, backend, fullstack, data, devops, etc.
work_modemultiComma-separated: remote, hybrid, onsite
senioritymultiComma-separated: junior, mid, senior, lead, etc.
companymultiCompany names, comma-separated (e.g. company=Stripe,Airbnb)
date_postedstringall, today, week, month
recentbooleantrue = only jobs fetched in last 24 hours
sortstringnewest, oldest, recently_fetched
offset, limitnumberPagination (or use page, num_pages)

Example URLs (search) — multiple values comma-separated:

/api/search?title=Engineer,Developer /api/search?country=us,uk /api/search?role_category=frontend,backend&work_mode=remote,hybrid /api/search?country=us,uk&seniority=senior,mid&date_posted=week

Jobs list endpoint: GET /api/v1/jobs/

ParameterTypeDescription
searchstringNatural language search (same as query on /api/search)
companystringFilter by company name (single value)
locationstringFilter by location substring (single value)
work_modestringremote, hybrid, onsite (single value)
senioritystringjunior, mid, senior, etc. (single value)
date_postedstringtoday, week, month
sortstringComma-separated fields (e.g. -posted_at, title)
fieldsstringComma-separated response fields to return
page, limitnumberPagination (limit max 100)

Example URLs (v1 jobs):

/api/v1/jobs/?search=engineer /api/v1/jobs/?company=Stripe&work_mode=remote /api/v1/jobs/?location=Berlin&date_posted=week
