FRONTEND UPDATE — ADD USER EMAIL, NAME & SURNAME TO JOB APPLICATIONS
=======================================================================

You already implemented apply / my applications / withdraw via BFF. This prompt adds
the missing applicant fields: email, first name, surname.

Backend stores and returns them on every application record. You only need to update
your BFF POST body and UI types/display.

-------------------------------------------------------------------------------
WHAT CHANGED ON THE BACKEND
-------------------------------------------------------------------------------

Table job_applications now has:
  external_user_email
  external_user_name      (first name)
  external_user_surname   (last name)

Every application API response includes ALL of these keys (always strings, "" if empty):

  external_user_id
  external_user_email
  external_user_name
  external_user_surname
  user_id              // same as external_user_id
  user_email           // same as external_user_email
  user_name            // same as external_user_name
  user_surname         // same as external_user_surname

Use either naming style in TypeScript; values are identical.

-------------------------------------------------------------------------------
FIX 1 — BFF APPLY ROUTE (required)
-------------------------------------------------------------------------------

You probably only send external_user_id today. Update to send full profile from session.

--- app/api/app/jobs/[jobId]/apply/route.ts ---

  const user = await getSessionUser(); // your existing Breneo session helper
  if (!user?.id) return NextResponse.json({ success: false, message: "Unauthorized" }, { status: 401 });

  const res = await fetch(`${process.env.JOB_AGGREGATOR_BASE_URL}/api/jobs/${params.jobId}/apply`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Application-Key": process.env.EMPLOYER_POST_SECRET!,
    },
    body: JSON.stringify({
      external_user_id: String(user.id),
      external_user_email: user.email ?? "",
      external_user_name: user.firstName ?? user.name ?? "",
      external_user_surname: user.lastName ?? user.surname ?? "",
    }),
  });

Map from YOUR session user shape (adjust property names):

  | Breneo / your session | Send to aggregator        |
  |-----------------------|---------------------------|
  | user.id               | external_user_id          |
  | user.email            | external_user_email       |
  | user.firstName        | external_user_name        |
  | user.lastName         | external_user_surname     |

CamelCase aliases also accepted by backend if easier:
  email, firstName, lastName

FIX 2 — TYPESCRIPT TYPES
-------------------------------------------------------------------------------

Extend JobApplication (or Application) interface:

  interface JobApplication {
    id: number;
    external_user_id: string;
    external_user_email: string;
    external_user_name: string;
    external_user_surname: string;
    user_id: string;
    user_email: string;
    user_name: string;
    user_surname: string;
    job_id: number;
    status: string;
    applied_at: string;
    is_withdrawn: boolean;
    withdrawn_at: string | null;
    job: JobSummary;
  }

Helper for display:

  function applicantDisplayName(app: JobApplication) {
    const name = app.external_user_name || app.user_name || "";
    const surname = app.external_user_surname || app.user_surname || "";
    return [name, surname].filter(Boolean).join(" ") || "Applicant";
  }

  function applicantEmail(app: JobApplication) {
    return app.external_user_email || app.user_email || "";
  }

-------------------------------------------------------------------------------
